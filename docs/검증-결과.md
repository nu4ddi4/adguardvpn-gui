# 0.5.0 검증 범위

## 확인한 내용

- GTK 가상 화면과 외부 CLI 프로세스를 연결한 통합 테스트
- 제공된 프리미엄 응답의 계정·최대 10대·2031-08-31 표시 (stdout·stderr 각각)
- 오류·미로그인 (종료 코드 0 및 1)·알 수 없는 응답·시간 초과·실패 후 복구
- 일반·선택 목록의 독립적 추가·삭제와 명시적 모드 적용
- 편집 목록만 바꿨을 때 실제 적용 모드가 바뀌지 않는지 확인
- 잘못된 URL·CLI 옵션 형태·범위를 벗어난 CIDR 거부
- 업데이트 버전 비교·다른 출처의 다운로드 URL 거부·중복/잘못된 체크섬 거부
- 공개 프로젝트 릴리스 RPM의 실제 다운로드·SHA-256 검증

기본 테스트 11개와 공개 네트워크 테스트 1개를 실행했습니다.

## 실계정·실제 네트워크와의 구분

GTK 통합 테스트는 사용자께서 제공한 응답을 재현하는 외부 CLI 대역을 사용했습니다.
공식 CLI 1.8.2도 확인했으나 이 환경에는 로그인된 AdGuard 계정이 없습니다.
실계정 프리미엄 인증과 VPN을 통한 실제 사이트별 트래픽 경로는 검증하지 못했습니다.
시스템 인증 창의 사용자 비밀번호 입력도 이 클라우드 환경에서는 재현하지 않습니다.
