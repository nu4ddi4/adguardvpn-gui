# Fedora GTK 버전 설치 안내

1. 기존 AdGuard VPN GUI 창과 알림 영역의 앱을 종료합니다. VPN 연결은 유지할 수 있습니다.
2. [v0.5.0 릴리스](https://github.com/nu4ddi4/adguardvpn-gui/releases/tag/v0.5.0)의 `install-fedora.sh`를 내려받습니다.
3. 일반 사용자로 `bash install-fedora.sh`를 실행합니다. DNF 단계에서 관리자 비밀번호를 입력합니다.
4. 앱 메뉴에서 AdGuard VPN을 다시 실행합니다. 설정 하단의 앱 버전이 0.5.0이고 GTK 버전이 표시되는지 확인하세요.
5. 공식 CLI 로그인 버튼으로 로그인한 뒤 구독 정보 새로 고침을 누릅니다.

설치 스크립트가 x86_64·aarch64에 맞는 RPM을 선택하고 SHA-256을 확인합니다.
공식 CLI가 없으면 별도 설치하며, 비밀번호는 앱에 입력하지 않습니다.
설치 아이콘은 터미널을 열어 동일한 스크립트를 실행합니다. 파일 관리자의 실행 허용 설정이 필요할 수 있습니다.

## 직접 RPM 설치

```bash
sudo dnf install ./adguard-gui-fedora.x86_64.rpm
```

ARM64는 `adguard-gui-fedora.aarch64.rpm`을 사용하세요.
기존 설정과 계정 정보는 보존합니다. Qt용 패키지를 자동으로 삭제하지는 않지만 새 앱의 실행에는 필요하지 않습니다.
Fedora 43 이상 일반 데스크톱용이며, 불변 시스템은 간편 설치 대상이 아닙니다.

## 구독 정보를 읽지 못하는 경우

- 설정의 CLI 실행 경로와 터미널에서 로그인한 실행 파일이 같은지 확인하세요.
- 앱과 터미널을 같은 일반 사용자로 실행하세요.
- 구독 조회 응답 원문을 펼쳐 실행 실패와 출력 형식 오류를 구분하세요.
- 조회 실패를 미로그인이나 무료 구독으로 표시하지 않습니다.

## 삭제

```bash
sudo dnf remove adguard-gui
```

공식 CLI·사용자 설정·계정 정보는 유지합니다. 자동 시작은 삭제 전 앱에서 끄세요.
앱별 예외는 포함하지 않습니다. 사이트 예외 화면에서 ‘목록 사이트 제외’ 또는 ‘목록 사이트만 적용’을 선택하고 모드 전환 버튼으로 적용하세요.

앱 자동 업데이트는 새 RPM을 확인·다운로드·검증한 뒤 Fedora 시스템 인증으로 설치합니다.
관리자 인증을 취소하면 기존 앱을 유지합니다. 새 버전 사용에는 앱 재실행이 필요합니다.
실계정 인증·VPN 경로 검증은 테스트 환경에 계정이 없어 수행하지 못했습니다.
