# Fedora 설치 안내

## 가장 간단한 설치

1. [v0.3.0 릴리스](https://github.com/nu4ddi4/adguardvpn-gui/releases/tag/v0.3.0)에서 `install-fedora.sh`를 내려받습니다.
2. 파일이 있는 폴더에서 터미널을 열고 `bash install-fedora.sh`를 실행합니다.
3. 관리자 비밀번호를 입력합니다. 앱과 의존성을 설치한 뒤 필요한 경우 공식 VPN CLI를 추가 설치합니다.
4. 앱 메뉴의 **AdGuard VPN**을 실행하고 **계정**에서 로그인합니다.

스크립트에 `sudo`를 붙이지 마세요. 로그인·VPN 실행은 일반 사용자 계정에서 진행합니다.
스크립트 자체의 안내는 한국어이며, DNF와 AdGuard 공식 설치 프로그램은 시스템 언어 또는 원문으로 표시될 수 있습니다.

## 아이콘으로 설치

릴리스의 `install-fedora.desktop`을 내려받아 바탕 화면이나 파일 관리자에서 실행할 수 있습니다.
Fedora GNOME 보안 정책에 따라 실행 권한과 **실행 허용** 설정이 먼저 필요할 수 있습니다.
파일 관리자가 실행기를 지원하지 않으면 위의 설치 스크립트 방법을 사용하세요.
설치 아이콘은 터미널을 열어 해당 릴리스의 설치 스크립트를 내려받아 실행합니다.

## RPM만 설치하거나 업데이트

```bash
sudo dnf install ./adguard-gui-fedora.noarch.rpm
```

이미 설치된 경우 같은 명령으로 새 버전 RPM을 적용합니다. 이전 버전으로 자동으로 되돌리지는 않습니다.
공식 CLI가 없다면 간편 설치 스크립트를 권장합니다.

이미 받은 로컬 RPM을 간편 설치에 사용하려면 다음을 실행합니다.
로컬 RPM은 사용자가 선택한 파일이므로 릴리스의 온라인 체크섬 검사를 생략합니다.

```bash
bash install-fedora.sh --rpm ./adguard-gui-fedora.noarch.rpm
```

공식 CLI 설치를 건너뛰려면 `--skip-cli`를 추가하세요.

## 지원 범위

- 일반 Fedora 데스크톱의 x86_64·aarch64, Python 3.10 이상, PySide6 6.7 이상
- Fedora 43 컨테이너에서 RPM을 빌드하도록 구성했습니다.
- Silverblue·Kinoite 등 rpm-ostree 시스템은 설치 스크립트가 중단됩니다.
- Fedora GNOME에서 알림 영역을 사용하려면 해당 기능을 제공하는 확장이 필요할 수 있습니다.
- 알림 영역을 사용할 수 없는 경우 창을 닫으면 앱이 종료됩니다. VPN 연결은 공식 CLI가 관리합니다.
- 앱 설치·계정 로그인·VPN 연결·화면 실행 테스트는 아직 수행하지 않았습니다. 현재 사전 배포판입니다.

RPM에는 공식 CLI를 묶지 않습니다. 별도의 서명되지 않은 로컬 RPM을 설치하며, 시스템의 패키지 서명 정책은 변경하지 않습니다.
`SHA256SUMS`는 내려받은 파일의 무결성을 확인하는 용도입니다.

## 언어와 실행 경로

처음 실행하면 한국어를 사용합니다. 기존 언어 선택이 있으면 **설정 → 앱 → 언어**에서 변경하세요.
기본 설치 위치의 CLI는 `PATH` 또는 `/opt/adguardvpn_cli/adguardvpn-cli`에서 찾습니다.
다른 위치에 설치했다면 **설정 → 앱 → adguardvpn-cli 실행 파일 경로**에 지정하세요.

## 삭제

```bash
sudo dnf remove adguard-gui
```

공식 VPN CLI·계정 정보·사용자 설정은 삭제하지 않습니다.
자동 시작을 사용했다면 삭제 전 앱 설정에서 끄세요.
앱 삭제 후 남은 자동 시작 항목은 다음 명령으로 제거할 수 있습니다.

```bash
rm -f ~/.config/autostart/adguard-gui.desktop
```

사용자 설정 초기화가 필요할 때만 `~/.config/adguard-gui/config.json`을 직접 삭제하세요.
