사이트 예외 편집과 자동 업데이트를 추가한 GTK 한국어판입니다.

- 사이트·와일드카드·IP·CIDR 추가·삭제, 모드별 목록 편집
- 일반 모드: 목록 사이트는 VPN 제외 / 선택 모드: 목록 사이트에만 VPN 적용
- 목록 전환은 편집 목록만 바꾸며, ‘이 모드로 전환’을 눌러 실제 적용합니다.
- 앱 자동 업데이트: 시작 후 및 6시간마다 사전 배포판을 포함해 새 버전 확인·다운로드·SHA-256 검증 후 DNF 설치
- 설치 시 Fedora 시스템 인증이 필요할 수 있습니다. 인증을 취소하면 기존 앱을 유지하고 수동 재시도를 제공합니다.
- 설치 후 앱을 다시 실행해야 새 버전을 사용합니다. VPN CLI 자체는 이 기능으로 업데이트하지 않습니다.

앱별 예외는 요청에 따라 제외했습니다. 사이트별 선택 모드는 앱별 선택 모드와 별개입니다.
실계정 자격 증명이 없어 실제 프리미엄 인증·VPN 패킷 경로까지 검증하지는 않았습니다.
제공된 구독 출력으로 GTK 화면·외부 CLI 프로세스 통합, 사이트 편집·모드 적용, 실패 복구와 체크섬 검증을 테스트했습니다.

기존 앱을 종료하고 이 릴리스의 `install-fedora.sh`를 받아 `bash install-fedora.sh`로 업데이트하세요.
