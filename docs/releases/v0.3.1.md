로그인·구독 표시를 보완한 Fedora용 사전 배포판입니다.

- 로그인 버튼을 누르면 공식 `adguardvpn-cli login`을 터미널에서 실행합니다.
- 이메일·비밀번호 입력란을 제거하고 로그인 후 5분 동안 구독 정보를 다시 조회합니다.
- 계정 화면에 구독 정보 새로 고침 버튼을 추가했습니다.
- 표준 오류 출력과 이메일 없는 로그인 안내를 처리하고, 알 수 없는 구독을 무료로 표시하지 않습니다.

`install-fedora.sh`를 내려받아 `bash install-fedora.sh`로 실행하면 업데이트됩니다.
앱은 Qt 6 기반입니다. GTK 4·libadwaita 전환은 포함하지 않습니다.
실제 설치·로그인·VPN 연결 테스트는 수행하지 않았습니다.
