Rust·GTK 4·libadwaita로 전환한 Fedora용 한국어 사전 배포판입니다.

- 로그인 버튼으로 공식 CLI 터미널을 열고, 구독 정보를 주기적으로 갱신합니다.
- 계정·프리미엄 등급·기기 수·만료일을 나누어 표시합니다.
- 조회 실패와 미로그인을 구분하며, 실제 실행 파일과 응답 원문을 확인할 수 있습니다.
- 설정 하단에서 앱·GTK·libadwaita 버전을 확인할 수 있습니다.
- Qt 런타임 대신 GTK 런타임을 사용하며 기존 사용자 설정을 보존합니다.

기존 앱을 종료하고, 이 릴리스의 `install-fedora.sh`를 내려받아 `bash install-fedora.sh`로 업데이트하세요.
x86_64·aarch64용 RPM을 제공합니다. Fedora 43 이상의 일반 데스크톱이 대상입니다.

GTK 전환판의 고급 라우팅·상세 SOCKS·사이트 예외 편집·CLI 업데이트는 공식 CLI에서 관리합니다.
실제 설치·로그인·구독 연동·VPN 연결 테스트는 수행하지 않았습니다.
