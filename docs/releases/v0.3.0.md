한국어를 기본으로 사용하는 Fedora 우선 배포판입니다.

- 앱 화면·대화상자·설정·알림 영역 메뉴를 한국어로 제공하며, 한국어 서버 검색을 지원합니다.
- Fedora용 `adguard-gui-fedora.noarch.rpm`과 간편 설치 스크립트를 제공합니다.
- 설치 스크립트가 RPM의 SHA-256을 확인하고 DNF로 의존성을 설치합니다. 공식 CLI가 없으면 AdGuard의 설치 프로그램을 실행합니다.
- 누락된 업데이트 분석 모듈과 RPM 소스 빌드 단계를 보완했습니다.

Fedora 일반 데스크톱의 x86_64·aarch64용입니다. Silverblue·Kinoite는 이번 배포 범위에 포함하지 않습니다.
`install-fedora.sh`를 내려받아 `bash install-fedora.sh`로 실행하세요. 관리자 비밀번호 입력 후 설치하며, 계정 로그인은 직접 진행합니다.

GUI 실행·로그인·VPN 연결·실제 시스템 설치 테스트는 아직 수행하지 않은 사전 배포판입니다.
`SHA256SUMS`는 전송 파일의 무결성 확인용이며, RPM에 별도 서명은 하지 않았습니다.
원본 프로젝트의 MIT 라이선스와 저작권 표기를 유지합니다. AdGuard의 공식 앱은 아닙니다.
